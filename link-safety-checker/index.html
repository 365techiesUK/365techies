// GOOD QUESTIONS

Frequently asked

What does the link safety checker do?

It examines a web address for the tell-tale signs of a phishing or scam link — things like a missing secure connection, an IP address instead of a domain, disguised characters, or a shortened link that hides where it really goes — and explains what it finds in plain English.

Does it open the link?

No — and that’s deliberate. We only read and analyse the address in your browser, so it’s completely safe to check a link you’re unsure about.

If it says ‘no red flags’, is the link definitely safe?

It’s reassuring, but not a guarantee — a clean-looking address can still be malicious. Always ask yourself: were you expecting this link? If a message feels off, don’t click — check with us.

I’ve clicked a bad link — what now?

Don’t panic. Don’t enter any details, close the page, and if you already typed a password, change it straight away. See our I’ve been scammed guide, or call us — we’ll help.

Where can I learn to spot scams myself?

Try our free Spot the Scam quiz and our online safety hub — both in plain English, no jargon.

Had a suspicious message?

Forward it, screenshot it, or just describe it — we’ll tell you if it’s a scam and what to do, with no judgement. Helping Dorset stay safe online since 1995.

// HOW IT WORKS

How to check if a text message link is a scam

To check if a text message link is a scam, copy the link and paste it into this free checker, which reads the web address in your browser and flags the phishing warning signs scammers use — without ever opening the link — so you can decide before you tap.

Warning signs this checker looks for in a link's address (in your browser, without opening it):

  • Not secure (no HTTPS) — the connection isn't encrypted, so never enter passwords or card details.
  • An IP address instead of a domain name — a classic phishing sign.
  • An '@' in the address — text before an @ is ignored by browsers and used to disguise the real destination.
  • Disguised 'punycode' (xn--) characters — can make a fake site look identical to a real one.
  • A shortened link (bit.ly, tinyurl, t.co and similar) — hides where it really goes.
  • A long chain of subdomains — lots of dots used to look official.
  • An unusual domain ending (e.g. .zip, .tk, .xyz, .top, .click) — used far more by scam sites.
  • An unusually long web address — can hide the true destination.

Step by step

  1. Copy the link, don't tap it — On a phone, press and hold the link in the text message and choose 'Copy link' instead of opening it.
  2. Paste it into the checker — Paste the full address, including the part before the first slash, into the box.
  3. Run the safety check — Press 'Check this link' — the tool examines only the address in your browser and never visits the site.
  4. Read the warning signs — See the plain-English verdict and any red flags, such as a shortened link, an IP address, a disguised '@', or an unusual domain ending.
  5. When in doubt, don't tap — A clean result is reassuring but not a guarantee; if the message was unexpected, don't tap the link and check with the sender or with 365 Techies.

Good to know

How can I tell if a link in a text message is a scam?

Genuine couriers, banks and companies rarely ask you to tap a link and pay a fee or log in; watch for shortened links, an IP address instead of a name, misspelt brand names, an '@' in the address or an odd domain ending — paste the link into this checker to have those signs flagged for you.

Does this checker actually open or visit the link?

No — and that is deliberate. It only reads and analyses the address text in your browser, so it is completely safe to check a link you are unsure about; it never loads the page.

Does the checker scan the link against a virus or blocklist database?

No — it inspects the address for common phishing tells rather than scanning a live threat database, so a clean result means no obvious red flags, not a guaranteed-safe site; if a message feels off, don't tap the link.
