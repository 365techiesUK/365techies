Sage 50 won’t print to PDF on Windows 11

Sage 50 won’t print to PDF on Windows 11? Nine times out of ten it’s Sage’s own built-in PDF driver, knocked out by a recent Windows or Office update — not your printer. Here’s the fix in the right order, and friendly Dorset help if you’re up against a deadline. Rated 4.9 on Google.

/01 — THE QUICK ANSWER

What’s actually going wrong when Sage 50 won’t print to PDF

Sage 50 prints and emails your invoices, statements and reports as PDFs through its own built-in printer driver — the Sage PDF driver, based on the Amyuni Document Converter — not your normal office printer. So when Sage 50 won’t print to PDF on Windows 11, it’s that little internal driver that has been damaged, mis-configured or blocked, almost always by a recent Windows or Microsoft 365 update. The fix is to repair or reinstall that driver — touching your everyday printer won’t help.

Try the two fastest things first. Save your work, restart the PC fully (a proper restart, not just sign out), then reopen Sage and try again — a good number of PDF failures clear the moment a half-finished update settles. If it still fails, close Sage, right-click the Sage 50 icon and choose Run as administrator, and try once more; missing permissions are the next most common cause.

If neither works, resist the urge to keep hitting Print — you’ll only queue up error messages. The rest of this page walks the fix through in the right order, from safe five-minute checks to the deeper driver reinstall, and shows where we can simply jump on remotely and sort it for you if invoices are stacking up.

/02 — WHY WINDOWS 11 BREAKS IT

Why Windows 11 (and Office) updates break Sage’s PDF printing

Sage’s PDF engine is a virtual printer — historically the Amyuni Document Converter, shown in Windows as something like Sage PDF or Sage 50 Document Converter. When you choose Print, Preview, Publish or Email in Sage, your report is quietly ‘printed’ to that driver, which turns it into a PDF. Anything that damages that driver stops the whole chain.

On Windows 11 the usual culprits are:

  • A Windows or Office update that strips the permissions the driver needs, removes the printer, or changes how drivers are trusted. That’s why it so often ‘stops working overnight’ when nothing else changed — see why Windows updates break things.
  • Missing administrator rights, or User Account Control blocking the driver from running.
  • The wrong converter selected, or the Sage printer’s port pointing somewhere other than where it should.
  • A damaged Windows user profile, so PDFs work for one login but not another.

You might see a specific message such as ‘Printer not activated — error code 20’ (or -30 / -41), or the PDF may simply never appear. Those activation codes point squarely at the driver and its registry permissions rather than anything wrong with your accounts — your figures are safe throughout.

/03 — THE FIX, IN ORDER

How to fix it yourself, in the right order

Work through these from the top and stop as soon as PDFs start working again. Take a Sage backup first (File, then Backup) — it’s good practice before any change, and it protects far more than just printing.

  • 1. Restart Windows fully and try printing to PDF again before touching anything else.
  • 2. Run Sage as administrator — right-click the icon, choose Run as administrator, and retry.
  • 3. Check the Sage printer still exists — in Windows Settings > Bluetooth & devices > Printers & scanners, look for the Sage PDF / Document Converter printer. If it’s gone, the driver has been removed.
  • 4. Reinstall the Sage PDF driver — in Sage, open Help > About (or System Information), click through to the program directory, find the PDF folder and run its install file as administrator.
  • 5. Restart the Print Spooler — press Windows+R, type services.msc, right-click Print Spooler and choose Restart.
  • 6. Repair Sage 50 — Windows Settings > Apps, select Sage 50, then Modify > Repair.

Once PDFs work, print a test invoice to confirm before you rely on it for a real run. If you’d rather not poke around registry-level fixes on a working accounts machine, that’s exactly the sort of thing we sort out remotely every week — safely and without guesswork.

/04 — LAYOUT, NOT DRIVER

When it’s the invoice layout, not the driver

Sometimes every other document turns into a PDF perfectly well, but one specific invoice or report fails — or you see ‘Sage report designer is unable to generate report: out of memory’. That isn’t the driver at all. The usual cause is an oversized company logo or image embedded in that particular layout.

Sage has to load the full-resolution image every time it builds the PDF, and a large, photo-sized logo can exhaust the memory available to a single report. Swapping it for a smaller, lower-resolution version — a few hundred pixels wide is plenty for print — usually fixes it instantly. A corrupted custom layout can behave the same way; testing with one of Sage’s standard layouts quickly tells you which of the two it is.

It’s also worth separating two different problems. ‘Won’t make a PDF at all’ is the driver. ‘Makes the PDF, but the email never sends’ is usually Outlook or your mail settings instead — we cover that on Sage 50 won’t email invoices through Outlook. Knowing which side of that line you’re on saves a lot of wasted troubleshooting.

/06 — STOP IT COMING BACK

How to stop it happening again

Because Windows and Office updates are the main trigger, a few simple habits keep Sage printing reliably:

  • Take a Sage backup before big updates — and know how to restore it. It protects far more than just printing.
  • Test a PDF invoice after any Windows feature update, especially the larger annual ones, so you find a problem in calm time rather than at month-end.
  • Keep Sage 50 itself up to date — newer versions ship with a converter built for current Windows 11 builds.
  • Don’t bloat your invoice logo — keep embedded images small and print-friendly.
  • Run day to day as a well-configured user rather than fighting UAC prompts each time you print.

If Sage also feels sluggish alongside the PDF trouble, that’s worth ruling out separately — see why QuickBooks and Sage run slowly. And if you run Sage across more than one PC and someone can’t get in at all, that’s usually a network or data-service matter rather than printing — we cover it on Sage 50 multi-user cannot connect. // GOOD QUESTIONS

Frequently asked

Why does Sage 50 use its own PDF printer instead of Microsoft Print to PDF?

Sage builds every emailed or saved invoice, statement and report through its own virtual printer — the Sage PDF driver, based on the Amyuni Document Converter — because it needs precise control over the layout. That’s handy, but it means PDF creation depends on that one driver staying healthy. When it’s damaged, having Microsoft Print to PDF installed doesn’t help, because Sage simply isn’t using it.

What does ‘Printer not activated — error code 20’ (or -30) mean?

It’s the Sage PDF driver telling you it can’t run — usually because a Windows or Office update changed the permissions it needs, the wrong converter is selected, or Sage isn’t running with enough rights. Codes -20, -30, -40 and -41 all point at the same driver. Your accounts data is fine; it’s purely the printing component that needs repairing or reinstalling.

It worked yesterday and I changed nothing — why did it stop?

Almost always an overnight Windows or Microsoft 365 update. Updates can remove the Sage printer, reset the permissions on its registry keys, or change how Windows 11 trusts drivers — and none of that shows up as an obvious warning. Restarting fully and reinstalling the Sage PDF driver is the standard fix; if it keeps recurring, your update history is worth a look.

Sage prints to paper fine but won’t create a PDF. Is that different?

Yes. Printing to paper uses your normal printer driver; making a PDF uses the separate Sage PDF driver, so one can work perfectly while the other fails. If paper printing is fine but PDFs won’t generate, focus entirely on reinstalling and repairing the Sage PDF driver rather than touching your office printer — that’s the part that’s actually broken.

It makes the PDF but the email never leaves — same problem?

No — if the PDF is created but the email doesn’t send, the driver is working and the issue is with Outlook or your mail setup instead. That’s a different fix, which we walk through on Sage 50 won’t email invoices through Outlook. Checking whether the PDF actually appears is the quickest way to tell the two problems apart.

What we can’t do is bypass a genuine Sage licensing or account-status issue; if your problem turns out to be a subscription or a version Sage no longer supports, we’ll tell you honestly and point you to Sage rather than charge for something we can’t resolve.

Sage 50 Accounts is Windows software — it isn’t made for Mac — and we’re Windows and Android specialists, so Windows PCs are exactly our territory. If you’re running Sage on Windows 11 and it won’t print to PDF, that’s squarely something we fix. Give us a call and we’ll get you sorted.
