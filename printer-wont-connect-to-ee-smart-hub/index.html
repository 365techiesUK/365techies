// EE SMART HUB PRINTER HELP

Printer won’t connect to your EE Smart Hub

Swapped to EE and now your printer refuses to find the wifi? You’re not alone — the EE Smart Hub hides your printer’s favourite 2.4GHz signal behind one shared network name, and older printers get lost. Here’s the plain-English fix, and how we can sort it remotely if you’d rather not poke around in hub settings. Rated 4.9 on Google.

/01 — THE QUICK FIX

The quick answer

If your printer won’t connect to your EE Smart Hub, the usual cause is that the hub broadcasts its 2.4GHz and 5GHz wifi under a single network name and quietly steers devices between the two bands — yet almost every home printer can only see the slower 2.4GHz band. When the hub parks your printer on 5GHz, the printer simply can’t find the network. The dependable fix is to switch on EE’s Compatible WiFi: a separate, 2.4GHz-only network built for exactly this problem. Connect your printer to that and it stays put.

Compatible WiFi runs on WPA2 security by default, which is another reason it works — some older printers can’t handle the WPA3 security the newest EE hubs use on their main network. You turn it on in the EE app or the Hub Manager, give it a name and password, then run your printer’s wireless setup against it. The full step-by-step is further down this page.

Different situation? We have sister guides for a printer that won’t connect to a BT Smart Hub, a printer and a Sky router, or a printer that’s vanished after a house move.

/02 — WHY EE HUBS TRIP PRINTERS UP

Why it happens on an EE hub

Three things about EE’s newer hubs catch printers out:

  • Band steering. The EE Smart Hub Plus and Smart Hub Pro use one name for both wifi bands and decide which band each device gets. A printer that only speaks 2.4GHz can be handed a 5GHz connection it can’t use.
  • WPA3 security. The latest hubs default to WPA3, a newer encryption standard. Plenty of printers that are only a few years old were built for WPA2 and quietly refuse to join a WPA3 network.
  • The BT-to-EE switch. When BT customers moved across to EE, many received a brand-new hub with a different wifi name and password. Your printer still remembers the old BT network, so it keeps trying to connect to a wifi that no longer exists.

That last one is the most common call we get. The printer isn’t broken and nothing you did was wrong — the wifi it was told to use has simply changed underneath it. Once you point the printer at a network it can actually see and log in to, it behaves again. If your printer connects but then keeps dropping off, our guide on why printers keep disconnecting covers that separately.

/03 — CONNECT VIA COMPATIBLE WIFI

The reliable fix: use Compatible WiFi

Here’s the approach that works on the vast majority of EE Smart Hubs. The precise menu labels vary a little by hub model and firmware, but the shape is always the same.

First, get into the controls. The easiest route is the EE app on your phone. If you’d rather use a computer, open a web browser and type 192.168.1.254 (or eehub) into the address bar, then sign in with the admin password printed on the pull-out card on the back of the hub — that’s a different password from your wifi one.

Next, find Advanced Settings, then Wireless, then Compatible WiFi, and switch it on. Give it a name and password you’ll recognise and save. Now, on the printer itself, run the wireless setup wizard, pick that Compatible WiFi name and type the password carefully — capital letters matter. Keep the printer within a few metres of the hub while it joins, and give the hub a couple of minutes to settle after any change.

The full checklist is in the numbered steps below. If your printer only offers WPS (the one-button method), there’s a specific EE quirk covered there too. Prefer to watch someone do it? We can screen-share and walk you through it remotely.

/04 — MAC FILTER & WPA3 RED HERRINGS

Two things that send you down the wrong path

Two messages send people hunting for problems that aren’t really there when a printer won’t connect to an EE hub.

The ‘MAC address filtering’ report. Some printers — HP models in particular — run a self-test that claims a MAC address filter is blocking them. On EE Smart Hubs this is usually a false alarm: EE’s current hubs don’t use MAC filtering on the main network, so there’s nothing there to switch off. The printer’s diagnostic is guessing at why it failed and landing on the wrong reason. Don’t spend an afternoon looking for a filter that isn’t there — the real issue is nearly always the band or the security type.

WPA3 versus WPA2. If your printer genuinely won’t accept the password on the main network, the security standard is the likely culprit. Connecting through Compatible WiFi sidesteps it, because that network uses WPA2. If you’d rather keep everything on one network, some hubs let you set the main wifi to a WPA2/WPA3 transition mode, which keeps old and new devices happy. Not every hub or firmware version offers that, so Compatible WiFi remains the simplest, most reliable fix.

/05 — WHICH EE HUB HAVE YOU GOT?

Which EE hub do you have?

Knowing your hub helps, because the wording differs slightly:

  • EE Smart Hub Plus — the dual-band WiFi 6 hub. It uses one network name across both bands, and it’s where the Compatible WiFi option lives.
  • EE Smart Hub Pro — the newer WiFi 7 hub. Faster, but its stronger default security is exactly what trips older printers up, so the same Compatible WiFi fix applies.
  • BT Smart Hub 2 — if you moved from BT to EE you may have kept this one. It’s WiFi 5 and behaves like its BT self, so our BT Smart Hub guide is the better match for you.

Whichever you have, you reach the settings the same way: the EE app, or a browser pointed at 192.168.1.254 (or eehub), using the admin password from the card on the back. Newer firmware may load the Hub Manager over a secure https address and warn you the page isn’t private — that’s normal for a device on your own home network, and you can safely continue. Need a hand with the wider setup? See our home network setup help.

// GOOD QUESTIONS

Frequently asked

Why did my printer stop working when I switched from BT to EE?

Your new EE hub almost certainly has a different wifi name and password from your old BT one, and your printer is still trying to join the network that no longer exists. On top of that, EE’s newer hubs use band steering and stronger WPA3 security that some printers can’t follow. Re-running the printer’s wireless setup against EE’s 2.4GHz Compatible WiFi sorts it out.

Does the EE Smart Hub have a separate 2.4GHz network for printers?

Yes — it’s called Compatible WiFi. It’s a distinct 2.4GHz-only network using WPA2 security, designed for older devices and printers that struggle with the main network. You switch it on in the EE app or the Hub Manager, give it its own name and password, and connect the printer to that. It runs alongside your main wifi, so your other devices are unaffected.

My printer says a MAC address filter is blocking it — is that true?

Usually not. Several printers run a self-check that reports a MAC address filter when they fail to connect, but EE’s current hubs don’t use MAC filtering on the main wifi, so there’s nothing to disable. Treat that message as a red herring — the real cause is almost always the wrong band or WPA3 security, and Compatible WiFi gets around both.

Can I split the 2.4GHz and 5GHz bands instead?

You can, but on the Smart Hub Plus it’s effectively the same job as Compatible WiFi: on later firmware you switch the main network’s 2.4GHz radio off and run the 2.4GHz band as its own named network, then point the printer at that. It works, but it’s fiddlier, and not every hub or firmware version offers it yet. For most people, simply turning on Compatible WiFi and leaving the main network alone is the quicker, tidier route to the same result.

I can’t find Compatible WiFi in my hub settings.

That feature only appears once your hub has the latest firmware, so a small number of hubs won’t show it yet. Leaving the hub switched on overnight usually lets it update itself. If it still isn’t there, the next best step is to switch the main wifi to a WPA2/WPA3 transition mode where the hub offers it, so older printers can still join — or let us take a look remotely and pick the best option for your hub.

Should my printer use WPA2 or WPA3?

Most home printers older than a year or two are built for WPA2. EE’s newest hubs default to WPA3, which those printers can’t join. Compatible WiFi uses WPA2, so it’s the safe choice. If you’d rather stay on one network, some hubs offer a WPA2/WPA3 transition mode that accepts both old and new devices.

Can you just set this up for me?

Gladly. Most EE-hub printer jobs we handle remotely, usually the same day — with your permission we connect to your Windows PC, enable Compatible WiFi on your hub and re-run the printer’s setup while you watch. If it needs hands-on work we cover Bournemouth, Poole, Christchurch and Dorset for home visits and collection. Call 01202 775566 or get in touch.

What if the printer still won’t connect after all this?

Then the printer itself may be at fault rather than the hub. A failing wifi card, a corrupted driver, or a very old printer that can’t handle a modern hub can all cause it. We’ll test honestly and tell you whether it’s worth repairing or replacing — and because we’re no-fix-no-fee, you only pay if we get it working.

Printer still ignoring your EE hub?

We’ll enable Compatible WiFi and get your printer back online — usually remotely, the same day, no-fix-no-fee.
