Outlook not showing new emails that are on the server

If webmail shows messages that never appear in Outlook — and the folder just says “this folder is up to date” — the mail has reached your account but Outlook isn't displaying it. Usually it's a stalled sync, a hidden view, or a stale offline copy of the folder. Here's how to force it through, in order. Rated 4.9 on Google.

The quick answer

“This folder is up to date” but mail is missing — why

When webmail shows messages Outlook doesn't — and Outlook cheerfully reports “this folder is up to date” or “all folders are up to date” — the mail has genuinely arrived at your account. The problem is between the server and what Outlook is drawing on your screen. There are three usual culprits:

  • A stalled sync or Outlook sitting in Work Offline, so it isn't actually pulling the newest items.
  • A hidden view — a sort, filter or corrupt view setting that pushes new mail off-screen even though it's downloaded.
  • A stale offline copy of the folder (the OST cache) that has drifted out of step with the server.

This affects every version — classic Outlook, Microsoft 365 and the new Outlook. Work the steps in order and stop as soon as your mail reappears. The early steps are instant and safe; the later ones (clearing offline items, rebuilding the OST) re-download the folder from the server, so nothing is lost for a Microsoft 365, Exchange or IMAP account. (The Send/Receive, Reset View and Clear Offline Items steps below are classic-Outlook features; on the new Outlook, force a sync with the View > Sync button or F9 instead.)

Start here

Force the sync and un-hide the view

These are instant and completely safe. Most people are fixed by step 3.

  1. Click Send/Receive All Folders (F9). On the Send / Receive tab, click Send/Receive All Folders, or just press F9. This forces every folder to pull from the server, not just the inbox.
  2. Make sure Work Offline is off. Still on the Send / Receive tab, check the Work Offline button isn't highlighted and the status bar doesn't say “Working Offline.” If it does, click it once to reconnect.
  3. Reset the folder view. If webmail shows the mail but Outlook still doesn't, a view is hiding it. Go to the View tab, click Reset View (or View Settings then Reset Current View). Also check you haven't left a sort or filter applied — click the column header to sort by Date (newest on top), and clear any search or filter still in the box. Corrupt or filtered views are the single most common reason new mail “vanishes.”

If it persists

Refresh the offline copy and rebuild the OST

If the mail is still missing, Outlook's local copy of the folder has drifted from the server. These steps rebuild it. On a Microsoft 365, Exchange or IMAP account your mail lives on the server, so clearing and rebuilding is safe — everything re-downloads. (If yours is an older POP account, mail may only exist on your PC — back up your data file first and check with us before deleting anything.)

  1. Clear Offline Items, then Update Folder. Right-click the problem folder in the folder list, choose Properties, and on the General tab click the Clear Offline Items button. Then on the Send / Receive tab click Update Folder (or press Shift + F9). Outlook empties the stale local copy and re-downloads the real contents from the server.
  2. Check no rule is diverting the mail. Go to File then Manage Rules & Alerts and look for any rule that moves or deletes incoming messages. Disable anything that could be pulling mail out of your inbox before you see it.
  3. Rebuild the OST if it still persists. The .ost is Outlook's offline cache; if it's corrupt, deleting it forces a clean rebuild from the server. Close Outlook, then in File Explorer paste %localappdata%\Microsoft\Outlook into the address bar, rename the account's .ost file (for example to .ost.old), and reopen Outlook. It rebuilds a fresh, fully-synced copy automatically. Again, this is safe for 365/Exchange/IMAP — the mail comes back from the server.

Note: rebuilding an OST is different from repairing a PST with scanpst — the OST is a disposable cache you can safely rebuild, whereas a PST holds your only copy and must be repaired, not deleted. If you're unsure which you have, don't delete anything — let us check.

If new mail still won't show after a clean rebuild, the fault is deeper (a profile, add-in or account issue), and that's the moment a quick remote session is worth it. // GOOD QUESTIONS

Frequently asked

Outlook says “this folder is up to date” but new emails are missing — what's wrong?

The mail has reached your account but Outlook isn't displaying it. It's usually a stalled sync, a hidden or corrupt view, or a stale offline copy of the folder. Press F9 to Send/Receive All Folders, make sure Work Offline is off, reset the view and check your sort/filter — that fixes most cases.

Webmail shows the email but Outlook doesn't — how do I fix it?

Because the mail is clearly on the server, the fault is local to Outlook. Reset the folder view (View > Reset View), clear any sort or filter, then right-click the folder > Properties > Clear Offline Items and click Update Folder to re-download it. If it still won't show, rebuild the OST cache.

What does “Clear Offline Items” do — will I lose emails?

It empties Outlook's local cached copy of that folder (right-click the folder > Properties > Clear Offline Items), then re-downloads the real contents from the server via Update Folder. For a Microsoft 365, Exchange or IMAP account nothing is lost — your mail lives on the server. Only be cautious with older POP accounts, where mail may exist only on your PC; back up first and check with us.

How do I rebuild the OST file in Outlook?

Close Outlook, open File Explorer, paste %localappdata%\Microsoft\Outlook into the address bar, rename the account's .ost file (e.g. to .ost.old), then reopen Outlook. It rebuilds a fresh, fully-synced copy from the server automatically. This is safe for 365/Exchange/IMAP accounts — the mail re-downloads.

Is rebuilding the OST the same as running scanpst?

No. The OST is a disposable offline cache you can safely delete and rebuild from the server. A PST holds your only copy of the mail and must be repaired with scanpst, never deleted. If you're not sure which file type your account uses, don't delete anything — let us check first to avoid data loss.

Could a rule be hiding my new emails in Outlook?

Yes. A rule can move incoming mail to another folder or delete it before it reaches your inbox. Go to File > Manage Rules & Alerts and review them; disable anything that diverts or deletes incoming messages, then press F9 to sync and check your inbox again.
