Windows 11, Without the Head-Scratching

A free, gentle course for anyone whose computer moved things about and never explained itself. Seven short lessons at your own pace, plain English throughout, and a printable certificate with your name on it at the end — from the family-run team at 365 Techies in Bournemouth, helping people with computers since 1995.

// WHAT’S IN THIS COURSE

7 short lessons, at your own pace

Every lesson ends with one gentle “what would you do?” question — no scores, no time limits, no pass marks. Here’s what you’ll cover:

  1. The Desktop, the Taskbar and the Start Button. Windows 11 is the version of Windows on most computers sold since late 2021, and if you moved to it from an older version, the first thing you noticed was probably that everything shifted to the middle.
  2. Settings: Where Everything Lives Now. Older versions of Windows hid their controls in something called the Control Panel.
  3. Windows Update, and Why You Let It Run. Every few weeks Windows fetches updates: fixes for security holes, small improvements and occasionally new features.
  4. Bigger, Clearer, Louder: Windows Accessibility. Windows 11 has a whole section devoted to making the computer easier to see, hear and use, and none of it costs anything or needs an expert.
  5. Where Your Things Live: File Explorer and OneDrive. Every file on the computer — letters, photos, downloads — sits in a folder, and File Explorer (the yellow folder on the taskbar) is the window that shows them.
  6. Signing In: PINs, Passwords and Your Microsoft Account. Windows 11 usually asks for a PIN when it starts — four or more digits — and the PIN causes more confusion than any other part of the computer.
  7. When Windows Grumbles: Restarts, Notifications and Getting Help. Windows will occasionally sulk — a program that stops responding, a message that makes no sense, a noise you didn’t ask for.

// KEEP THIS BY THE COMPUTER

Your one-page checklist

The whole course, boiled down to the reminders that matter. Print it and keep it near the computer.

  1. Find anything by typing: click the Start button (the Windows logo, now in the middle) and just start typing its name.
  2. Settings is where everything lives — Windows key and I — and it has its own search box at the top.
  3. Real updates arrive only through Settings, Windows Update. A website or email demanding an urgent update is a scam.
  4. Save your work before a restart for an update, then leave it alone until it finishes — never switch off partway through.
  5. Too small? Accessibility, Text size. Small print in a hurry? Windows key and plus opens the Magnifier; Windows key and Escape closes it.
  6. A cloud icon beside a file means OneDrive has a safe copy online too — the file is still on your computer.
  7. Switch on Storage Sense (Settings, System, Storage) and let the computer tidy itself.
  8. The PIN unlocks this computer only; the Microsoft account password is the real key. Keep the password on paper at home.
  9. Something misbehaving? Restart, not Shut down — on Windows 11 only Restart clears everything.
  10. An error message? Windows key, Shift and S to take a picture of it before you close it. Stuck? 365 Techies, 01202 775566.

// GOOD QUESTIONS

Frequently asked

Is this course really free?

Completely. No payment details, no catch and no time limit. We’re a family-run IT firm in Bournemouth, and courses like this are our way of helping local people feel confident with technology.

I’m still on Windows 10. Is this course any use to me?

Most of it, yes — Settings, updates, accessibility, File Explorer and PINs all work in much the same way, though the Start button sits in the corner and some pages look a little different. Lesson three explains what changed for Windows 10 in October 2025 and why it’s worth deciding what to do rather than ignoring it. We’re happy to talk it through.

Why does the Start button sit in the middle now?

Microsoft moved it there in Windows 11. It does exactly what it always did. If you preferred it in the corner, Settings, Personalisation, Taskbar has a taskbar alignment option that puts it back — lesson two shows you where.

Can I break something by changing settings?

Not the ones in this course. Text size, the Magnifier, notifications, the Start button’s position and Storage Sense all switch straight back. Where a setting matters more — signing in, updates — the lessons say so and explain what to expect.

Do I get a certificate?

Yes — when you finish, you can print a 365 Techies certificate of completion with your name on it. It’s our own certificate rather than a formal qualification, but plenty of people pin it up, and it’s earned.

What if I get stuck partway through?

Take your time — there’s no clock, and the course will wait for you. If something has you truly stuck, help is one phone call away on 01202 775566, and we run friendly in-person lessons at the Kinson Community Centre in Bournemouth.

Rather learn with a friendly human?

We run patient, plain-English computer lessons at the Kinson Community Centre — and we’re on the phone Mon–Fri, 9–5. No silly questions, ever.
