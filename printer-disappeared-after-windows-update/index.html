// PRINTER GONE AFTER WINDOWS UPDATE

Your printer disappeared after an update?

Your printer was there yesterday and now it’s gone from Windows 11 — not offline, just missing from the list. Don’t panic: it’s almost always still installed. Here’s the calm, honest fix order, from a 30-second spooler restart to rolling the update back as a last resort. Rated 4.9 on Google.

/01 — START HERE

Printer disappeared after a Windows 11 update? Start here

If your printer has disappeared from Windows 11 after an update, it is almost always still there — the update has broken the software link to it, not physically removed the printer. In the great majority of cases you can get it back by restarting the print spooler, re-adding the printer, or reinstalling its driver, and only rarely do you need to roll the update back.

First, work out whether it is truly gone or just hidden. Windows 11 has two places that list printers: the modern Settings ’ Bluetooth & devices ’ Printers & scanners page, and the older Devices and Printers window. Sometimes a printer disappears from the new Settings page while it is still listed in the old window. To open that classic window reliably, press Windows key + R, then copy and paste this exact line and press Enter: shell:::{A8A91A66-3A7D-4424-8D24-04E180695C7A}. (On current Windows 11 builds the old ‘control printers’ shortcut often just bounces you back to the Settings page, so we use this instead.) If your printer is listed in the classic window, it is installed and printing should still work — the Settings page simply isn’t showing it, which points to a software glitch rather than a lost printer.

It also matters whether your printer is plugged in by USB cable or connected over your Wi-Fi or network. If it went missing after a house move or a new router rather than an update, the cause is different — see our guides for the BT Smart Hub, Sky router, EE Smart Hub and after moving house.

/02 — WHY IT HAPPENS

Why a Windows update makes a printer vanish

A Windows update touches the printing system in several ways, and any of them can make a printer disappear. The most common cause is the driver — the small piece of software that lets Windows talk to your exact model. A big update can replace, disable or remove that driver, and if nothing valid is put back in its place the printer drops off the list. Microsoft has also been retiring older printer drivers that it used to hand out automatically through Windows Update, so a machine that relied on one of those can be left with nothing after an update. If you want the plain-English version of what a driver is, see our driver jargon-buster.

The second common cause is the Print Spooler — the Windows service that queues and manages every print job. An update can leave the spooler stopped or in a confused state, and when it isn’t running your printers simply won’t show. A third possibility is simpler still: the printer is fine underneath, but the modern Settings page just isn’t displaying it — which is why the classic Devices and Printers window is worth checking first.

Finally, updates can reset USB port permissions or wipe the saved port or IP address of a network printer. The exact update behind any one case varies, so we work through the fixes in order rather than guessing. Our page on why Windows updates break things explains the wider pattern.

/03 — SPOOLER FIRST

Restart the Print Spooler — the 30-second first fix

Because a stopped or stuck spooler is the quickest thing to rule out, start there. Press Windows key + R, type services.msc and press Enter. Scroll down to Print Spooler, right-click it and choose Restart. If Restart is greyed out, choose Start. While you are there, double-click Print Spooler and check the Startup type is set to Automatic so it launches on its own next time.

If a restart alone doesn’t bring the printer back, a jammed print queue can be the culprit. The safe way to clear it is: in the same Services window, right-click Print Spooler and choose Stop. Then open Windows key + R, type %windir%\System32\spool\PRINTERS and press Enter, and delete everything inside that folder (you are only deleting stuck print jobs, not anything important). Go back to Services and Start the Print Spooler again.

Now check Settings ’ Bluetooth & devices ’ Printers & scanners to see if the printer has reappeared. A spooler restart on its own fixes a surprising number of ‘disappeared after update’ cases in under a minute. If your printer keeps dropping off even between updates, that is a slightly different pattern — our guide on why a printer keeps disconnecting covers it.

/04 — RE-ADD & REINSTALL

Re-add the printer and reinstall a clean driver

If the spooler is running and the printer is still missing, re-add it. Go to Settings ’ Bluetooth & devices ’ Printers & scanners and click Add device. Wait a few seconds; if Windows finds it, click Add. If it doesn’t appear, click Add manually (sometimes shown as ‘The printer that I want isn’t listed’). For a USB printer, unplug the cable, wait ten seconds and plug it back in — ideally into a different USB port directly on the computer, not through a hub. For a network or Wi-Fi printer, you may need to add it by its IP address, which you can usually print from the printer’s own menu or find in your router.

If it is a driver problem, the most reliable fix is a clean driver from the maker rather than a generic Windows one. Go to your printer manufacturer’s official website — HP, Epson, Canon or Brother — find your exact model, and download their full driver or software package for Windows 11. Before installing the new one, it is worth removing the old, broken driver: in Printers & scanners, open the printer and choose Remove, then install the freshly downloaded package and restart. A driver straight from the maker matches your model exactly and avoids the gaps left when an update strips out an older built-in driver.

/05 — LAST RESORT

Rolling back the update — and its trade-offs

Rolling the update back is a genuine option, but it is the last resort, not the first, because Windows updates also carry important security fixes. Only reach for it if printing broke immediately after a specific update and the steps above haven’t helped. To remove a recent quality update, go to Settings ’ Windows Update ’ Update history ’ Uninstall updates, find the most recent update dated around when the problem started, and choose Uninstall, then restart.

If the trouble started after a big feature update (for example moving up a version of Windows 11), you may instead see a Go back option under Settings ’ System ’ Recovery — but only for a limited window, usually around ten days, after which Windows deletes the old files and the button greys out. A full System Restore to a point before the update is another route, though it also undoes other settings and program changes made since that point, so back up anything important first.

Two honest caveats: Windows will often try to reinstall the same update later, so you may need to pause updates for a while; and if the driver has genuinely been retired, rolling back only buys time rather than fixing it for good. If you’re not comfortable weighing security against a working printer, this is a good moment to ask us. Our guide on how to update Windows safely has more.

// GOOD QUESTIONS

Frequently asked

Has the update actually deleted my printer?

Almost never. A Windows 11 update breaks the software link to the printer — the driver, the spooler or the saved connection — rather than removing the hardware. The quickest proof is to press Windows key + R, paste shell:::{A8A91A66-3A7D-4424-8D24-04E180695C7A} and look in the classic Devices and Printers window that opens; if the printer is still listed there, it is installed and just hidden from the new Settings page.

Why did a Windows update make my printer disappear?

Usually one of three things: the update replaced or removed the printer’s driver and didn’t put a working one back; the Print Spooler service was left stopped; or the modern Settings page simply isn’t displaying a printer that is still installed. Microsoft has also retired some older printer drivers it used to supply automatically, which can leave an older printer with nothing after an update.

How do I restart the Print Spooler?

Press Windows key + R, type services.msc and press Enter. Scroll to Print Spooler, right-click it and choose Restart (or Start if it is stopped). Double-click it and make sure the Startup type is Automatic. This alone fixes a large share of ‘printer gone after update’ cases, so it is always worth trying first.

My printer shows in Devices and Printers but not in Settings — what now?

This can happen after some Windows 11 updates: the printer is installed and working, but the modern Printers & scanners page isn’t showing it. In the meantime you can keep using and managing the printer from the classic Devices and Printers window (Windows key + R, then paste shell:::{A8A91A66-3A7D-4424-8D24-04E180695C7A}). Restarting the Print Spooler and installing later Windows updates often restores the Settings view.

Should I roll back the Windows update?

Only as a last resort. Windows updates also patch security holes, so removing one has a real cost. Try the spooler restart, re-adding the printer and a fresh driver from the maker first. If printing clearly broke the moment a specific update installed and nothing else helps, uninstalling that update is reasonable — but Windows may reinstall it later, so you may need to pause updates too.

Will I lose my documents or print history?

No. Clearing the print queue only removes stuck or waiting print jobs, not your saved files, and reinstalling a driver or re-adding the printer doesn’t touch your documents. The one exception is a full System Restore, which rolls back Windows settings and installed programs to an earlier point — so if you go that route, back up anything important first, just in case.

Can you just sort this out for me?

Yes — it’s one of the most common jobs we do. With your permission we connect remotely to your Windows PC, restart the spooler, strip out the broken driver, install a clean one from the maker and re-add the printer, usually in a single short session and often the same day. We’re no fix, no fee, so if we can’t get it back you don’t pay. Call 01202 775566 to get started.

Can you guarantee it won’t happen again after the next update?

We can’t promise that, and we won’t pretend to — Windows updates are outside anyone’s control and the same problem can return. What we can do is install the right driver straight from the maker, set the spooler to start automatically and show you the two-minute fix so a repeat is quick to clear. If your printer is an older model whose driver has been retired, we’ll advise honestly on the best long-term option.
